# Statistical Methods

Every routine lives in `packages/stats`, carries its equation and reference in its
docstring, and is tested against fixtures generated by `tools/reference/`
(numpy/scipy) at |Δ| < 1e-9 for deterministic quantities. This document states each
method, its defaults, and its assumptions.

## Transforms and standardization

For raw value y and assay transform f: x = f(y); z = (x − μ)/σ against the frozen
baseline (μ, σ) on the x scale. Transforms: `none`; `log` x = ln(max(y, 0.001))
(reader error is approximately multiplicative); `ratio_to_cutoff` x = y / cutoff_run,
with raw OD and the cutoff both stored. All rules and monitors consume z.

## Baseline (Phase I) — CLSI C24-Ed4 framing

Computed baselines require n ≥ 20 (10–19 allowed, flagged **provisional**); iterative
|z| > 3 exclusion, at most 2 passes, excluded ids recorded and confirmed by the
supervisor at freeze time. Classical mean/sample-SD is the default; the robust
option is median / 1.4826·MAD (both always shown). σ = 0 or n < 10 refuse to freeze.
Only frozen baselines feed monitoring; re-baselining creates a new dated row.

## Westgard multirule (Westgard et al., Clin Chem 1981)

Evaluated on the ordered stream of runs; each run is level → z-scores. Semantics that
matter:

- **1_2s** is a *warning* (inspection trigger), never a rejection in the classic
  profiles; a profile may promote it.
- **1_3s** rejects on |z| > 3 (strict inequalities everywhere: z = 2.0 exactly does
  not trigger a 2s rule).
- **2_2s** evaluated both within run (two controls beyond the same 2s limit) and
  across runs within a level (last two runs), per profile scope.
- **2of3_2s** within run, N = 3.
- **R_4s** within run only, classic definition: one control > +2s AND another < −2s
  (the range-only variant is deliberately off).
- **3_1s / 4_1s** k consecutive same-side |z| > 1, within level across runs or
  pooled across levels.
- **6x/8x/9x/10x/12x** k consecutive observations on the same side of the mean,
  per level and pooled. The pooled stream reproduces the published example where 6x
  fires while 2of3_2s does not (prev +0.5/+2.2/+1.7, current +2.1/+1.8/+1.7).
- **7T** (off by default) seven strictly monotonic observations.
- Look-back: rejected-and-not-accepted runs are excluded from across-run rules
  (configurable); supervisor-accepted runs are included.

Built-in profiles: `N2_classic` = 1_2s(warn)/1_3s/2_2s/R_4s/4_1s/10x;
`N3` = 1_2s(warn)/1_3s/2of3_2s/R_4s/3_1s/6x (9x available, off). Verdict = max
severity; every rule evaluation is persisted with the involved observation ids.

## EWMA (Roberts 1959; Lucas & Saccucci 1990; Neubauer 1997)

E_t = λ z_t + (1−λ) E_{t−1}, E_0 = 0; exact time-varying limits
±L·√(λ/(2−λ)·(1−(1−λ)^{2t})).

**Defaults: λ = 0.2, L = 2.962 (ARL₀ ≈ 500, Monte-Carlo verified ≈ 496).**
Sensitive preset λ = 0.1, L = 2.814 (ARL₀ ≈ 486; detects a 1σ sustained shift within
15 runs ≈ 91% of the time). The often-quoted (0.2, 2.86) pairing actually gives
ARL₀ ≈ 368 by simulation and was corrected — see `docs/validation.md`.

Shift estimate at signal: mean z over the last ⌈1/λ⌉ runs. A supervisor-acknowledged
signal marks a corrective action; the monitor restarts after that run. Assumes
independent, approximately normal z — autocorrelation inflates false alarms (stated
in the UI).

**Variance EWMA** (imprecision): V_t = λ z_t² + (1−λ)V_{t−1}, V_0 = 1, one-sided
upper limit. Because z² is χ²₁ (skewed), the limit is Monte-Carlo calibrated:
UCL = 2.927 (λ = 0.2) or 2.085 (λ = 0.1) for ARL₀ ≈ 500
(`fixtures/variance_ewma_calibration.json`).

## CUSUM (Page 1954; Montgomery)

Tabular two-sided: C⁺_t = max(0, C⁺_{t−1} + z_t − k), C⁻_t = max(0, C⁻_{t−1} − z_t − k);
signal when either exceeds h. Defaults k = 0.5 (tuned for a 1σ shift, k = δ/2),
h = 5 (ARL₀ ≈ 465; Monte-Carlo verified); h = 4 offered (ARL₀ ≈ 168). FIR head-start
h/2 optional. Onset estimate = last index at which the signalling sum was zero;
shift estimate = ±(k + C/N). Reproduces the Montgomery textbook example exactly.

## Change points (Killick, Fearnhead & Eckley 2012 — PELT)

L2 cost C(s,t) = Σy² − (Σy)²/n; penalty β = c·log n, c = 3 (tunable 2–6); minimum
segment 5. Supervisor retrospective tool only (online change detection is CUSUM's
job). Change points are annotated with lot/instrument/baseline events within ±3
runs. Measured performance (n = 100, shift 1.5σ at t = 50): detection ~100%,
localization ±3 ≈ 89%, ±5 ≈ 93% — matching exact optimal partitioning.

## Lot transition

Last n_A = 20 observations of the old reagent lot vs first n_B ≥ 10 of the new lot,
on the transformed scale: Welch t (Welch–Satterthwaite df), two-sided F test,
Brown–Forsythe Levene (median-centred), bias% with a Welch CI compared against the
assay's allowable bias. Output is advisory text; this is **not** CLSI EP26 (which
uses patient samples and is out of scope). Matches SciPy fixtures.

## Median polish (Tukey; R stats::medpolish)

Alternating row/column median sweeps with the R stopping rule
(|ΔΣ|r|| < eps·Σ|r|, eps = 1e-6, ≤ 10 iterations), masked-cell support,
median(α) = median(β) = 0. Matches fixtures generated by a line-for-line Python
replica of the R algorithm.

## PSAD — Plate Spatial Artifact Detector

See `docs/research.md` for motivation and claims. Mechanics:

1. Transform sample wells (log default; rank → Φ⁻¹((r−½)/n) for plates dominated by
   extreme positives; identity).
2. Median polish on sample wells only → μ, α_i, β_j, residuals r; scale
   s = 1.4826·MAD(r).
3. Statistics: T_row = max|α_i|/s (per-row z_i), T_col likewise; T_edge = (median
   perimeter − median interior)/s; least-squares plane → T_grad = ‖(b_r·R, b_c·C)‖/s;
   Moran's I on residuals (rook adjacency); local outliers |r_ij|/s > 3.5
   (Iglewicz–Hoaglin; reported as candidates, not permutation-tested).
4. Permutation null: B = 999 (199–4999) shuffles of the transformed values over
   sample wells (controls fixed), seeded PCG32;
   p = (1 + #{T_b ≥ T_obs})/(B + 1). Per-row/column p-values use the permutation
   distribution of the **max** statistic — family-wise error control without
   Bonferroni. α = 0.01 per family.
5. Guards: ≥ 40 sample wells required; if the assay declares plating
   `structured`, exchangeability fails and p-values are suppressed (effects still
   reported descriptively).

**Phase II** (≥ 30 validated plates): feature vector
v = [α₁..α₇, β₁..β₁₁, T_edge, b_r, b_c, s] (22 dims for 96 wells; one α and β
dropped for the median constraints), standardized by Phase-I means/scales, PCA
(cyclic Jacobi), retain components to 80% variance (cap 6);
T² = Σ t_a²/λ_a with UCL A(n−1)(n+1)/(n(n−A))·F_{1−α;A,n−A};
SPE = ‖v_s − P t‖² with the Jackson–Mudholkar limit; per-variable contributions
(e_k² for SPE) drive the "driven mostly by column 11–12 effects" explanations.

Calibration caveat (measured, see `docs/validation.md`): T² holds its nominal 1% false-positive
rate from ~30 training plates, but the Jackson–Mudholkar **SPE limit is anti-conservative** at
laboratory history sizes (~12% FP even at 120 plates, 22 dimensions). Treat SPE exceedances as
screening hints to be read with the contribution plot and the plate's own permutation findings;
an empirical-percentile SPE limit becomes viable once a few hundred plates exist.

## Distributions

Lanczos lgamma (g = 607/128, 15 terms); regularized incomplete gamma (series +
Lentz continued fraction) and incomplete beta (Lentz); normal quantile by Wichura
AS 241; t/χ²/F/Beta quantiles by safeguarded Newton with bisection fallback.
All cdf/quantile values match SciPy at 1e-9 over the fixture grid.

## RNG

PCG32 (O'Neill 2014), 64-bit state, seedable; matches the canonical reference
output for seed 42/seq 54. Used by PSAD permutations, Monte-Carlo tests, and the
demo generator, so every result in the product and this repo is reproducible.


## Run-log self-derived limits (the product's default mode)

When no baseline is frozen, the run log estimates limits from the entered runs with
three safeguards over the naive mean±kSD approach (each closing a genuine
statistical flaw):

1. **Leave-one-out standardization** — each run's flagging z uses limits estimated
   from the other runs (deletion form), removing self-inclusion bias (a suspect
   point can no longer shrink its own z). A robust screen (modified z > 3.5 on
   median/MAD) removes gross outliers from estimation entirely.
2. **Log scale for ratio data** — E-ratio limits and z-scores are computed on
   ln(E-ratio); displayed bands are back-transformed (geometric, asymmetric),
   correcting the skew-induced false-alarm asymmetry and preserving sensitivity to
   low-signal failures near the physical floor.
3. **Minimum history** — Westgard flags are suppressed below 6 kept runs; limits
   are displayed but marked provisional (the SD estimate is too uncertain for
   ±2/3 SD limits to hold their nominal error rates).
